Pourquoi apprendre HTML/CSS?

HTML et CSS sont les fondations du web.

Maîtriser HTML/CSS ouvre la porte à des métiers comme :

  1. Développeur front-end
  2. Intégrateur web
  3. Designer UI/UX
  4. Développeur full-stack (comme première étape)

Même si tu ne veux pas devenir développeur, connaître HTML/CSS te permet de :

  1. Créer ton propre portfolio ou blog
  2. Modifier un site WordPress ou Shopify
  3. Comprendre comment fonctionne le web

HTML/CSS sont incontournables avant d'apprendre JavaScript, React, Vue.js, etc.
Impossible d'aller plus loin sans ces bases.

Rapide à apprendre

Les bases de HTML/CSS s'acquièrent en quelques semaines avec une pratique régulière.
C'est l'un des meilleurs retours sur investissement en apprentissage tech.

Balises HTML

Les balises HTML sont utilisées pour structurer et formater le contenu d'une page web.
Par exemple :

  • <h1> - Titre principal
  • <p> - Paragraphe de texte
  • <ul> - Liste non ordonnée
  • <li> - Élément de liste
  • <a> - Lien hypertexte
  • <img> - Image
Indique au navigateur que le document est en HTML5. Toujours en première ligne.

<!DOCTYPE html>
<html lang="fr">
<head>
    ...
</head>
<body>
    ...
</body>
</html>


Contient les métadonnées invisibles : titre de l'onglet, encodage, lien vers le CSS…
                            
<head>
<meta charset="UTF-8">
<title>Mon site</title>
<link rel="stylesheet" href="style.css">
</head>

Styles CSS

Les styles CSS permettent de modifier l'apparence des éléments HTML.
Voici quelques propriétés courantes:

  • color - Couleur du texte
  • background-color - Couleur de fond
  • font-size - Taille de la police
  • margin - Marge extérieure
  • padding - Remplissage intérieur
  • border - Bordure

</head>

Tips & bonnes pratiques

  • Utiliser des balises sémantiques pour améliorer l'accessibilité et le référencement.
  • Organiser le code avec une indentation cohérente pour faciliter la lecture.
  • Utiliser des classes et des identifiants pour cibler les éléments avec CSS.
  • Tester le site sur différents navigateurs et appareils pour assurer la compatibilité.
  • Minimiser l'utilisation de styles en ligne et privilégier les fichiers CSS externes.
